# Créditos dos modelos 3D

## Personagens: Microsoft Rocketbox Avatar Library (licença MIT)
https://github.com/microsoft/Microsoft-Rocketbox (commit 0943055)
Copyright (c) 2020 Microsoft Corporation. Licença MIT.
Avatares usados: Military_Male_01, Military_Male_03, Police_Male_01, Male_Adult_04, Male_Adult_06,
Military_Female_01, Military_Female_02, Police_Female_01, Female_Adult_04, Female_Adult_08.
Animações: idle, walk, run e crouch (masculinas e femininas).
Alterações: convertidos de FBX para GLB, texturas reduzidas para 512 px (JPEG), escala em metros,
animações sem deslocamento (o jogo move o corpo) e sem os ossos do rosto.
